# プロダクト: ポモドーロタイマー

ポモドーロ・テクニックを実装したシングルページアプリケーション（SPA）。集中作業と休憩のサイクル管理をサポートする。バックエンドを持たず、Cloudflare Pages での静的ホスティングを前提として設計されている。

## 主な機能

- **タイマーモード**: 作業セッション（25分）、ショートブレイク（5分）、ロングブレイク（15分）
- **基本操作**: 開始・一時停止・リセット
- **フェーズ自動遷移**: セッション／休憩完了後に次のフェーズへ自動移行
- **サイクル進捗表示**: 現在のサイクル内の進捗をドットインジケーターで表示（デフォルト: 1サイクル4セッション）
- **通知**: フェーズ終了時にアラーム音 + ブラウザ通知（Web Notifications API）
- **設定**: 各フェーズの時間・1サイクルあたりセッション数をカスタマイズ可能。`localStorage` に永続化
- **統計**: 当日の完了セッション数を記録・表示。`localStorage` に永続化
- **タブタイトル**: タイマー動作中はブラウザのタブタイトルに残り時間とフェーズ名をリアルタイム表示
- **アクセシビリティ**: WCAG 2.1 AA 準拠を目標。`aria-live` 領域およびフルキーボード操作に対応

## 主な制約

- サーバーサイドレンダリング不使用 — 全ロジックはブラウザ上で実行
- 外部バックエンド API 不使用 — 永続化は `localStorage` のみ
- ビルド成果物は静的ファイル（HTML・CSS・JS）のみ
- インラインスクリプト不使用（CSP 準拠）
